Tenim el simulador web que funciona amb un algorisme Montecarlo Tree Search
El simulador té un cost computacional gran amb fins 450 simulacions que arriben a una profunditat de 6 branques i més de 200 en la búsqueda. 
El simulador permet visualitzar un csv que poden fer servir per a fer una IA per a 
* Decidir la millor jugada (Classificació)
* Predir la quantitat de simulacions, profunditat o counts (Regressió)
* Predir la certeça de guanyar amb un cert moviment
* Fer clusters de tipus de partida


També es pot fer un EDA

La IA deuria ser un analisi dels millors algorismes de classificacio i regressio i deep learning

Es podria fer un server al que es connecta el frontend, i el server va fent aprententatge per reforç
